## Descripción

Implementación de una base de datos NoSQL en MongoDB Atlas con cinco colecciones y 2.500 documentos, consultas de negocio, optimización mediante índices, operaciones CRUD e integración con una API REST desarrollada con Node.js y Express.

## Contenido del repositorio

- `ContentFlow_API`: código fuente y README con instrucciones de ejecución.
- `scripts_mongodb`: scripts de consultas, validaciones, índices y CRUD.
- `postman`: colección de pruebas de la API REST.
- `datos_originales`: cinco archivos JSON del caso.
- `Evidencias_EP2_MongoDB - parte 1` y `parte 2`: 104 capturas de respaldo.
